## Locked product position at the handoff checkpoint

Spotriq was explicitly defined as a **BSC financial-agent marketplace**, not a generic agent marketplace, workflow builder, multichain agent economy or DeFi chatbot.

Canonical journey:

`Understand → Discover → Match → Evaluate → Compare → Try → Authorize → Activate → Monitor → Measure → Reassess → Continue / Switch / Combine`

All four categories were mandatory and first-class:

1. Rebalancing
2. Grid Trading
3. Yield Optimisation
4. Health Factor Monitoring

The handoff explicitly warned: **do not overdevelop one category while leaving the other three as cosmetic cards.**

## Deterministic truth doctrine

The foundational handoff explicitly locked:

**AI explains. Deterministic systems decide.**

Deterministic systems own protocol reads, findings, readiness, compatibility, permission rules, evidence evaluation, activation safety and outcomes. AI may explain structured evidence but may not invent financial truth, capability, authority, trust, readiness, fees or outcomes.

## Evidence/failure doctrine

Evidence classes:

- Marketplace Observed
- Marketplace Derived
- External
- Operator Supplied

Search relevance is not capability proof. External reputation is not Spotriq trust. Registry identity is not financial-service readiness.

Spotriq must work with partial data and visibly represent `Could Not Assess`, `Insufficient History`, stale, undeclared, discovery-lead and unsupported states instead of fabricating completeness.

## Reconciliation significance at v0.21

v0.12 and v0.13 followed this roadmap directly: Test Lab, then deterministic matching.

From v0.14 onward, implementation moved into a deep Rebalancing-only sequence: Job Intent → bounded authority → trusted key/calldata guard → execution plan/boundary → financial session/readiness → controlled BSC Testnet execution → Activity/Outcomes → real A2A task-origin proof.

That work is valuable and mostly strengthens the original trust architecture, but it happened **before** the four genuine reference agents and all-category activation parity that the foundational roadmap expected. This is the central roadmap-sequence drift recorded in `SPOTRIQ_DRIFT_AUDIT.md`.
