# BNB Ecosystem Integration

Spotriq treats ecosystem integrations as provider/protocol layers, not as shortcuts around marketplace truth.

## BSC

BSC is the chain substrate for evidence, identity discovery, real read-only financial observation and testnet financial development. Chain 56 supports ERC-8004 discovery plus supported read-only Smart Money/reference-agent observation. Chain 97 remains the authority/execution sandbox. Mainnet observation does not approve Mainnet financial execution.

## ERC-8004

Spotriq uses ERC-8004 identity as canonical identity/ownership evidence. Registry identity does not imply marketplace readiness, commercial eligibility, authority or outcomes.

Official BNB Agent SDK reference:
`https://docs.bnbchain.org/developer-kit/bnbagent-sdk/quickstart-typescript/`

## BNB Agent Studio

Spotriq normalizes operator-declared Agent Studio deployment posture and reconciles it against canonical ownership, AgentService binding, A2A registration and Marketplace Test Lab evidence.

Spotriq does not run the `bag` CLI as part of normal marketplace operation and does not ingest Studio wallet passwords/private keys.

Official references:
- `https://docs.bnbchain.org/developer-kit/bnbchain-studio/quickstart/`
- `https://docs.bnbchain.org/developer-kit/bnbchain-studio/cli-reference/`

## ERC-8183

ERC-8183 is one paid-commercial adapter behind Spotriq's provider-neutral commercial kernel. Spotriq observes/reconciles canonical job/escrow state; ERC-8183 does not replace Offer, Quote, Hire, Activation or PermissionGrant.

Official BNB Agent SDK reference:
`https://docs.bnbchain.org/developer-kit/bnbagent-sdk/quickstart-typescript/`

## x402 / B402

Spotriq can reconcile immutable Quote terms against canonical settlement evidence. A browser/facilitator assertion such as `paid=true` is insufficient. Payment signing/dispatch remains disabled.

Official x402 reference:
`https://docs.cdp.coinbase.com/x402/welcome`

## PancakeSwap and Venus

PancakeSwap provides concentrated-liquidity and supported market/execution primitives. Venus provides lending-health and supported yield state. Spotriq can now route supported read-only protocol observations to BSC Mainnet or Testnet, while guarded financial execution remains Testnet-only. Protocol observations do not become invented performance claims or autonomous authority.
