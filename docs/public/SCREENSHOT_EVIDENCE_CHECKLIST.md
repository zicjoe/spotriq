2. Live Smart Money finding with evidence/provenance visible.
3. Agent profile showing canonical identity + Marketplace Test Lab + commercial/authority distinctions.
4. Compare surface showing deterministic comparison fields.
5. Offer/Quote/Hire/Activation or active relationship state.
6. Permission Checkout exact scope and blockers.
7. My Agents activity/outcome with transaction-observation truth.
8. Agent Advantage report showing `Could Not Assess` where appropriate.
9. Grounded AI explanation with cited evidence refs.
10. Smart Money Plan conflict/compatibility view.
11. Operator Workspace / Agent Studio reconciliation.
12. Public system health showing operational-only language.
13. “Why Spotriq” public BNB integration page.
14. `/v1/public/adoption` JSON response or captured evidence artifact.

For each screenshot record: UTC timestamp, production URL, what claim it supports, and whether the screen contains live or clearly-labelled sample data.
