# Demo Playbook

Target: a concise 6–10 minute judge/ecosystem walkthrough that demonstrates the complete product thesis without pretending unsupported financial performance.

## Gate 0 — Production proof

Show:
- `/health`
- `/v1/system/capabilities`
- `/v1/system/health`
- `/v1/public/adoption`

State explicitly that operational health is not marketplace readiness or financial safety.

## Gate 1 — Understand

Run Smart Money Check for a live supported wallet or use the clearly-labelled Example Portfolio when a deterministic category finding is needed for demo continuity.

Show the evidence provenance and `Could Not Assess` behavior where data is incomplete.

## Gate 2 — Discover and evaluate

Open a matched AgentService. Show:
- category/capability match;
- canonical ERC-8004 identity distinction;
- Marketplace Test Lab evidence;
- commercial terms;
- authority profile;
- BNB Agent Studio reconciliation where available.

Do not present external reputation or Studio deployment as Spotriq readiness.

## Gate 3 — Commercial lifecycle

Demonstrate:
`Offer → immutable Quote → idempotent Hire → Payment state → Activation`

For the four reference services, show the truthful FREE / READ_ONLY_SERVICE path and `Payment NOT_REQUIRED`.

## Gate 4 — Permission boundary

Open Permission Checkout and show the exact requested scope, assets/protocols, limits, expiry/revocation and blockers. Emphasize that Activation does not create PermissionGrant.

## Gate 5 — Runtime, activity and outcome

Run/read an Activation-bound task. Show the activity timeline, whether a transaction was actually observed, and the resulting financial outcome state. If no defensible measurement exists, show `Could Not Assess` instead of claiming success.

## Gate 6 — Agent Advantage

Open the Agent Advantage report. Explain the separate states for service contribution, transaction evidence, financial outcome and Agent Advantage.

## Gate 7 — Grounded AI

Generate a contextual explanation and inspect its cited deterministic facts. Explain that AI has no write/decision authority and falls back safely when provider output is invalid/unavailable.

## Gate 8 — Portfolio control

Show My Agents, switching/revocation and Smart Money Plans. Emphasize independent specialist Activations/PermissionGrants rather than a shared super-agent/signer.

## Gate 9 — Operator + BNB story

Show Operator Workspace and Agent Studio reconciliation. Explain how Spotriq can be the buyer-facing discovery/evaluation/activation front door while Agent Studio/SDK remains a provider/deployment layer.

## Closing statement

Spotriq's differentiator is not merely listing agents. It connects deterministic wallet need → evidence-backed specialist matching → commercial activation → scoped authority → guarded action → measurable outcome → reassessment, while keeping every truth boundary inspectable.
