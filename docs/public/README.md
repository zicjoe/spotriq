# Spotriq Public Launch Package

This directory is the public/adoption handoff for Spotriq v0.38.0.

Start here:

1. `ARCHITECTURE_AND_TRUST_BOUNDARIES.md` — what Spotriq is and which states are deliberately separate.
2. `BNB_ECOSYSTEM_INTEGRATION.md` — BSC, ERC-8004, BNB Agent Studio, ERC-8183, x402/B402, PancakeSwap and Venus roles.
3. `DEMO_PLAYBOOK.md` — the recommended judge/ecosystem demo flow.
4. `ADOPTION_EVIDENCE.md` — which claims are backed by repository/live evidence and how to capture them.
5. `SECURITY_AND_OPERATIONS.md` — security/production posture.
6. `SCREENSHOT_EVIDENCE_CHECKLIST.md` — exact production screenshots to capture after deployment.
7. `SUBMISSION_CHECKLIST.md` — final pre-publication gate.

Machine-readable public proof is available from `GET /v1/public/adoption` after v0.38 deployment.

Nothing in this package approves BSC Mainnet financial execution. Transactional/authority development remains BSC Testnet until explicitly approved.
